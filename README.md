# Psicotest26 - Gestão Inteligente e Metodologia Clínica

O **Psicotest26** é uma plataforma de elite desenvolvida para psicólogos que buscam transcender a gestão burocrática e focar na **Inteligência Clínica**. Utilizando as personas de IA **Liw** (Estrategista) e **Inu** (Acolhimento), o sistema transforma dados comportamentais em evolução real.

## 🚀 Diferenciais de Gestão Inteligente
- **Taxonomia Científica:** Testes baseados em PNL, Neurociência, Psicometria e Psicologia Positiva.
- **Jornada Gamificada:** Os personagens **Ínu e Vínu** (estilo Duolingo) acompanham o paciente.
- **Gatilho Motivacional:** O Ínu intervém a cada 7 perguntas para reduzir a evasão.
- **Prontuário Preditivo:** A Liw analisa correlações e sugere intervenções.

## 🛠️ Estrutura do Projeto
- `/data`: Base dos 50 testes comportamentais.
- `/src/gamification`: Gatilhos do Ínu e Vínu.
- `/docs`: Isca digital (Livro Ínu e Vínu).
